# Проект: Измерительно-калибровочный комплекс PN-2026 (ESP32)

Это подробная документация по гибридной прошивке PN-2026, разработанной для работы с многоканальным АЦП (ADS1115), физическим экраном (ILI9341), полноценным веб-интерфейсом и мгновенной передачей телеметрии в десктопное приложение Flutter.

## 1. Аппаратная часть (Железо)

### Основные компоненты:
* **Микроконтроллер:** ESP32 (рекомендуется ESP32-WROOM-32 / D0WD).
* **АЦП:** Модуль ADS1115 (16-бит, I2C).
* **Дисплей:** 2.8" TFT SPI на чипе ILI9341.
* **Питание:** 3S Li-ion сборка (номинал 11.1 В, макс 12.6 В, мин 9.6 В).

### Подключение пинов (Распиновка)
Прошивка жестко сконфигурирована под нестандартную распиновку для совместимости с текущей платой:

**Дисплей ILI9341 (Аппаратный SPI с переопределением пинов):**
* `SCK` (TFT_CLK) -> **GPIO 5**
* `SDI / MOSI` -> **GPIO 22**
* `DC` (Data/Command) -> **GPIO 15**
* `CS` (Chip Select) -> **GPIO 17** (TX2)
* `RST` (Reset) -> **GPIO 2** (подключен к синему светодиоду ESP32)

**АЦП ADS1115 (I2C):**
* `SDA` -> **GPIO 21**
* `SCL` -> **GPIO 19**
* Используются каналы `A1, A2, A3` (в коде они смещены как 1, 2, 3 для удобства).
* Прошивка содержит неблокирующий опрос (функция `adcFound` и `getLastConversionResults`), чтобы сбои на шине I2C или отсутствие АЦП не вешали плату.

**Кнопки управления (замыкаются на GND, подтянуты внутренним PULLUP):**
* `BTN_CH1` -> **GPIO 13**
* `BTN_CH2` -> **GPIO 12**
* `BTN_CH3` -> **GPIO 14**
* `BTN_MENU` -> **GPIO 27**

**Измерение напряжения (Вольтметр АКБ 3S):**
* **Пин:** `GPIO 34` (Использован АЦП1, так как АЦП2 не работает при включенном Wi-Fi).
* **ВНИМАНИЕ!** Необходимо использовать резистивный делитель напряжения!
* **Схема делителя:** Плюс АКБ -> Резистор `100 кОм` -> `GPIO 34` -> Резистор `10 кОм` -> GND. (Коэффициент 11:1).

## 2. Программная архитектура и Фичи

### Библиотеки (Зависимости)
Для компиляции в Arduino IDE / Arduino CLI требуются следующие библиотеки:
* `Adafruit_ILI9341`, `Adafruit_GFX` (Графика)
* `Adafruit_ADS1X15` (Работа с АЦП)
* `ESPAsyncWebServer` и `AsyncTCP` (Кастомные библиотеки для асинхронного веб-сервера)
* `Preferences` (Встроенная, для работы с энергонезависимой памятью)

### 1. Веб-сервер и Wi-Fi
* ESP32 поднимает собственную точку доступа Wi-Fi: **SSID:** `PN-2026_Live`, **Пароль:** `12345678`.
* IP-адрес интерфейса: **`192.168.4.1`**.
* Встроен **Captive Portal** (DNS перехватчик): при подключении со смартфона вас автоматически переадресует на главную страницу (редиректы прописаны для `hotspot-detect.html`, `generate_204` и т.д.).
* Веб-страницы (`INDEX_HTML` и `CALIB_HTML`) зашиты прямо в память (PROGMEM) в виде длинных строк, поэтому SD-карта не требуется.

### 2. Синхронизация целевых точек и расчет погрешности (γ)
* И экран ESP32, и веб-сайт в реальном времени высчитывают **приведенную погрешность** `E: X.XX%` или `γ: X.X%`.
* Чтобы они показывали одинаковые значения, в прошивке реализован механизм синхронизации:
  * Когда пользователь на сайте меняет количество точек (например, шаг -2.0, -1.5, -1.0...), сайт незаметно делает фоновый GET-запрос на `/api/set_points`.
  * ESP32 принимает этот массив точек, сохраняет в EEPROM (Preferences) и использует функцию `getNearestTarget(mm)` для поиска ближайшей точки к текущему положению.
  * Точно так же сайт использует `getNearestTargetJS(mm)` для верхней live-панели.
* В результате погрешность всегда рассчитывается корректно даже при отсутствии сигнала (0 мА = -3 мм, ближайшая точка -2.0 мм -> погрешность 25%).

### 3. Калибровка АЦП
* Помимо "Прогонки" на главном дашборде, есть скрытая сервисная страница: `192.168.4.1/calibrate`.
* На ней можно по двум точкам (минимум и максимум) рассчитать линейный множитель (`calibMult`) и смещение (`calibOffset`) для сырых значений миллиампер.
* Эти коэффициенты также навсегда сохраняются во флеш-памяти ESP32 через библиотеку `Preferences`.

### 4. Телеметрия по USB для Flutter
* Чтобы не блокировать веб-сервер и дисплей медленными функциями, обмен данными по USB сделан максимально легким.
* ESP32 генерирует короткую JSON строку вида:
  `{"ch1":{"ma":4.00,"mm":0.0},"ch2":...,"bat":{"volts":12.1,"percent":85}}`
* Отправка в Serial порт (115200 бод) происходит строго с частотой **20 Гц** (каждые 50 мс).

## 3. Перенос на другое устройство

Если вы решите перенести этот проект на новую плату или заново собрать прошивку:
1. Установите ядро **ESP32** версии не выше `3.x` (стабильная ветка).
2. Обязательно установите библиотеки **ESPAsyncWebServer** и **AsyncTCP** (именно форки, поддерживающие ESP32, скачанные с GitHub, так как их нет в стандартном менеджере библиотек).
3. При монтаже дисплея строго соблюдайте пины, указанные выше. Если поменяете пин RST с `2` на другой (например, `4`), придется обязательно поменять его в макросах `#define TFT_RST`. Иначе экран останется белым.
4. При подключении вольтметра АКБ обязательно используйте два резистора! Подключение 12V напрямую в порт мгновенно уничтожит контроллер.
